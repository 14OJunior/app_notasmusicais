# Treino de Ouvido Musical

App para treinar reconhecimento de notas musicais de ouvido, com sons reais de instrumentos.

## Como funciona
1. Escolha o modo: Natural (notas naturais) ou Com sustenidos
2. Clique em "Tocar nota"
3. Escolha qual nota você acha que ouviu
4. Ganhe pontos a cada acerto, com efeitos sonoros de feedback

## Tecnologias
- HTML, CSS, JavaScript puro
- Web Audio API (geração de som e reprodução de áudio real)

## Funcionalidades
- Modo Natural (7 notas) e Modo Com Sustenidos (12 notas)
- Sons reais de piano (gravados via ferramenta de piano virtual online)
- Efeitos sonoros de acerto e erro
- Interface colorida, com cor individual por nota
