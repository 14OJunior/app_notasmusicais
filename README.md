# Treino de Ouvido Musical
 App para treinar reconhecimento de notas musicais (DÓ, RÉ, MI...) de ouvido. 
 
 ## Como funciona 
 1. Clique em "Tocar nota" 
 2. Escolha qual nota você acha que ouviu 
 3. Ganhe pontos a cada acerto 
 
 ## Tecnologias- HTML, CSS, JavaScript puro
 - Web Audio API para geração de som
